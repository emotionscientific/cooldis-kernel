## breaks

The fix for both: put the agent in <b>version control</b>. Its definition and its whole history, with every change pointing at the reason.

## write-it-down

The notebook is the only door. Acting <b>is</b> writing it down, so the record cannot have holes.

## two-computers

Indexes and dashboards are green. Model answers, payment replies, and user messages are red. <i>Red goes in the notebook. Green is a cache.</i>

## arthur-merlin

Nobody asks the wizard again what he said. They read the transcript Arthur kept. That transcript is what <b>attestation</b> means.

## record

What happened? Line 48. Why? Line 43. Who allowed it? Line 47, by name. Nobody had to reconstruct anything.

## crash

Recovery means <b>reading the record</b>. No model call, no double refund. (And make the refund API idempotent too.)

## branch

This is how a change to the agent gets <b>tested before it ships</b>. Version control needs branches, and now the agent has them.

## checkpoint

A workflow and an agent are one dial, set <b>per step</b>. The refund path runs strict, the conversation runs adaptive, both on the same notebook.

## authority

Two laws, built in: a tool that is not <b>attached</b> does not exist, and every effect passes through one <b>door</b>. The judgment at the door can be swapped. The door cannot.

## observation

Watching from outside gives a good guess. The single door gives proof. The two stack: an auditor reads the proof through the monitoring dashboard.

## harness-data

The agent's harness is <b>data on the record</b>. When the agent changes itself, the change goes through the same door as a refund.

## placement

What an agent <b>may</b> do lives in its notebook, never in the machine. So it can move, and many tenants can share one host, each inside its own fence.

## should-did

Keep "should" and "did" separate but joinable. When they disagree, the difference is the incident, and it is already data.

## propagator

One record, three kinds of function around it. The loop <i>advances</i> it. Projections <b>derive</b> from it. Controllers steer what the loop does next. The agent is the loop and nothing more.
